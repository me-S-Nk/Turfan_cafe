# ТУРФАН — Version 02 / Cinematic landing page

Вторая дизайн-концепция сайта кафе «Турфан» в Астане. Визуальное направление вдохновлено cinematic landing pages: полноэкранный hero с фотографией, контрастная редакционная типографика, тёплые золотистые акценты, минимальная навигация, большие фотографии и появление блоков при прокрутке. Это самостоятельная реализация, а не копия чужого сайта.

## Запуск

Самый простой способ — открыть `index.html` в современном браузере. Для локального сервера:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Структура

- `index.html` — семантическая разметка и содержание страницы.
- `styles.css` — дизайн, адаптивные состояния, эффекты и анимации.
- `script.js` — мобильная навигация, фильтры карточек, reveal-анимации и год в футере.
- `assets/` — место для локальных фотографий/постера при подготовке к продакшену.

## Функции

- Responsive desktop/tablet/mobile layout.
- Мобильное полноэкранное меню, закрытие по Escape и по клику на ссылку.
- Фильтр тематических карточек.
- Появление секций через IntersectionObserver.
- Учёт `prefers-reduced-motion`.
- Ссылки на карты, страницу кафе и Google reviews.
- Секция часов, адреса, телефона и агрегированного рейтинга.

## Данные и важные ограничения

Данные из исходного CSV: название «Турфан»; адрес ул. Азербайжана Мамбетова, 10, Астана 020000, Казахстан; часы ежедневно 10:00–22:30; телефон +7 7172 39-08-50; рейтинг Google 4.3 и 3 739 отзывов на момент выгрузки; ссылка на страницу заведения `http://astana.restoran.kz/cafe/2142-turfan`.

В исходной выгрузке нет цен блюд, ссылок на меню, прямых фото, email и ссылок на соцсети. Поэтому карточки еды — имиджевые категории, не конкретные блюда; цены не придуманы. Фотографии загружаются с Unsplash как временные иллюстрации, не подтверждены как фото самого «Турфана». Google Maps и внешняя страница используются как ссылки. Часы и контакты стоит перепроверить перед публикацией.

## Перед продакшеном

1. Заменить стоковые фотографии на разрешённые фотографии заведения.
2. Подтвердить актуальные часы, телефон и рейтинг.
3. Получить актуальное меню и цены, добавить реальные позиции.
4. Проверить ссылки на целевых устройствах и прогнать визуальный QA в Chrome/Safari.
